Cartridge file

{}

One JSON object; an empty one is enough. The file itself is the marker: a stick without config.json is ignored, and a file that is not a JSON object is refused. Nothing inside it is read yet.

Reserved names at the root are never published: config.json, boot.png, README.txt, readme.txt, System Volume Information, $RECYCLE.BIN, .Trashes. Everything else at the root is part of the port 80 site.
